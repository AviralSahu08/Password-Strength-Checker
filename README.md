Features
1. Checks password length
2. Validates presence of uppercase & lowercase letters
3. Detects numbers and special characters
4. Prevents use of common passwords
5. Gives detailed feedback and strength rating

Running the Program
1. Make sure Python is installed on your system.
2. Open a terminal / command prompt.
3. Run the script
4. Enter a password when prompted to receive the evaluation.

How It Works
The program evaluates a password using the following rules:
Length - 8 characters or more
Letters	- Contains uppercase & lowercase
Numbers	- At least one digit
Symbols -	At least one special character
Security - Should not match common passwords
Based on the criteria matched, the program calculates a score and prints a final strength result:
1. Weak
2. Moderate
3. Strong
